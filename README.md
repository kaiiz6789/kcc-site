# KCC · Kai Card Center（一期 Demo）

充值買券、雙幣（抽獎券／積分）、固定份數獎池、尾刀、倒計時、積分兌黃金、個人中心。

## 規則摘要
1. 直接充值買抽獎券（非禮盒送券）
2. 1 張券 = 50 TWD
3. 平台抽成 30%
4. 抽獎券抽獎；積分兌黃金
5. 固定份數，賣完結束
6. 黃金只在積分兌換頁
7. 開卡動畫：通用卡框＋商品圖
8. 尾刀：最後一抽額外積分
9. 倒計時結束關閉，已消耗券不退
10. 個人中心：資產／帳單／地址／訂單
